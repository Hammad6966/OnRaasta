# OnRaasta

On-demand roadside assistance platform connecting stranded drivers with nearby mechanics in Pakistan.

## Stack

| Layer      | Technology                                      |
|------------|-------------------------------------------------|
| Mobile     | Flutter, Riverpod, GoRouter, Google Maps        |
| Backend    | Node.js, Express, MongoDB, Socket.IO, Twilio    |
| AI Service | Python, FastAPI, Uvicorn                        |
